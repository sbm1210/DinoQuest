# 🦖 DinoQuest · 소지섭의 공룡 탐험대

iPad Pro 11인치용 공룡 일일 퀘스트 숙제 관리 웹앱입니다.  
별도 서버나 빌드 과정 없이 정적 웹앱(GitHub Pages / 사파리 홈 화면에 추가)으로 바로 실행할 수 있습니다.

## 주요 기능
- **공룡 발자국 캘린더**: 월간 달력에서 매일의 올클리어 도장, 대기 중, 쉬는 날을 한눈에 확인
- **일일 퀘스트 & 부모 확인 → 보상 수령**:
  1. 아이가 숙제를 끝내고 **[다 했어요!]** 터치 → `부모님 불러주세요!` 표시
  2. 부모님이 채점·확인 후 PIN 입력 → **[확인 완료]** 또는 **[다시 풀기]** (피드백 메모 전달)
  3. 아이가 반짝이는 **[공룡 코인 받기!]** 버튼을 직접 눌러 폭죽·코인 비행·효과음 이펙트와 함께 수령
- **연속 달성 콤보(스트릭) & 일일 올클리어 보물상자**: 쉬는 날에는 스트릭이 깨지지 않고 유지
- **공룡알 부화 & 12종 공룡 도감 + 탐험 업적**: 올클리어를 모으면 공룡알을 3번 탭해 부화시키고 파트너 공룡을 교체 가능
- **선물 교환소**: 모은 공룡 코인으로 부모님이 설정한 선물 교환 (부모 PIN 확인 후 차감)
- **부모님 관리자 모드** (초기 비밀번호: `0000`, 설정에서 변경 가능):
  - 요일별 기본 주간 숙제 템플릿 관리
  - 특정 날짜/이번 주 내용 수정·제외·특별 숙제 추가·휴무 지정
  - 주간 보스 퀘스트 관리
  - 선물 상점·보너스 코인 지급 및 백업/복원 코드 지원

## iPad Pro에서 앱처럼 쓰기
1. 이 폴더를 GitHub Pages 등에 배포하거나 로컬 웹 서버로 엽니다.
2. iPad Safari에서 접속한 뒤 **공유 버튼 → "홈 화면에 추가"** 를 선택합니다.
3. 홈 화면의 `DinoQuest` 아이콘으로 실행하면 전체화면 앱처럼 동작합니다.
